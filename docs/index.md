# C5.0 GPL

This project modernizes the single-threaded C5.0 Release 2.07 GPL Edition while
preserving its learning behavior and serialized model format. It provides a C
library, a header-only C++11 facade linked to that library, compatible command
line programs, and Python 3.12-or-newer bindings.
